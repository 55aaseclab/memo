## I · 执行摘要

**是什么**：Memo 把"人生关键时刻"（住店/租车/打车/公交/烹饪）做成两类工具——瞬间的**时刻卡**（60 秒清单+水印拍照）与过程的**流程卡**（时间线+定时器），产出带时间水印的**凭证**归档为个人 Memo；出纠纷时走"出事了"通道直接调证。

**为什么现在**：① 取证存证赛道（权利卫士 35 万律师用户、12 万篇裁判文书引用）验证了"电子证据司法认可"已被大众接受，但其产品不懂消费场景；② 短视频平台"退押金避坑"内容持续高热，获客通道现成；③ 国内小程序/PWA 基建成熟，单文件产品试错成本极低。

**建议动作**：**继续跟进（有条件）**——花 ≤¥5 万、6 周完成两个验证（C 端付费率、B 端试点签约），数据回来升级为"推进尽调"或 Pass。

## II · 推荐动作 + 核心理由 + 关键风险

### 🎯 推荐动作：继续跟进（有条件）

**✅ 核心理由 3 条**

1. **空白真实且被竞品反向验证**：取证工具（权利卫士）是通用法律工具、不懂场景；垂直巡检（Damage iD，客户 Avis/Hertz/Amazon DSP）立场在商家。"站在用户立场、按场景驱动的留证工具"无人占据——两个竞品的存在恰好证明需求两侧都成立。
2. **试错成本极低，期权结构好**：单文件 PWA 无后端，验证期投入 ¥20–40 万（人力为主）；跑通情景 24–36 月收入 ¥100–500 万 [假设]，MOIC 3–6x；跑不通残值（代码+模板库）≈ 投入 10–20%。
3. **频率约束已被产品解法解除**：时刻卡天然低频（否决订阅），但事件时间轴 + Memo 台账（到期日历）双引擎把触点拉到每周级 [假设，待验证]——订阅制（¥99/年）从"不可行"变为"待验证"。

**⚠️ 关键风险 3 条**

| 风险 | 缓释 |
|---|---|
| R1 大平台功能化挤压：携程/美团/贝壳做"交割留证"对它们是一个功能，对我们是全部 | 不到场对抗：做平台不做的对抗立场（帮用户 vs 平台）与长尾市场；12–18 个月窗口内积累场景模板库与判例数据 |
| R2 C 端付费意愿零实证：¥9.9/次、¥99/年全是纸面推演 | 付费测试前置（100 个真实被扣押金用户，转化率 >5% 则商业模式上修，<2% 则砍 C 端收入线） |
| R3 需求频率假设依赖触达通道：服务号消息到达率不达标则时间轴死亡 | 双通道兜底（服务号+短信兜底节点）；到期日历作为不依赖事件的第二频率引擎 |

## IV · 市场与赛道

- **TAM**（口径：中国 C 端"关键时刻工具"订阅 + B 端中小商户白标 SaaS）：C 端按 2 亿出行人群 × 5% 付费 × ¥99/年 ≈ ¥10 亿/年 [假设，天花板口径]；B 端按 50 万家单体酒店/民宿/中小租车行 × 10% 渗透 × ¥3000/年 ≈ ¥1.5 亿/年 [假设]。
- **SOM（3 年）**：C 端 20 万付费 × ¥99 ≈ ¥2000 万/年；B 端 500 家 × ¥3000 ≈ ¥150 万/年 [假设]。
- **Why Now（3 条，附事实）**：
  1. 司法认可度就绪：可信时间戳证据 2024–2026 年被 12 万+ 篇裁判文书引用（权利卫士官方口径，tsa.cn）。
  2. 获客通道就绪：小红书/抖音"避坑清单"类内容为成熟流量品类，链接直达 H5 的转化路径无需应用商店。
  3. 低频约束被解法破除：事件时间轴 + 到期日历（本产品 V1 规划）将"用完即走"变为"持续看护"，参照滴滴/携程对"行程前后"通知位的教育成本已被巨头垫付。

## V · 产品与技术

- **核心价值主张**：清单是入口，留证是价值，凭证是资产。
- **差异化 Top 3**（事实）：
  1. 场景驱动拍摄（清单定义"拍什么"）——通用取证工具（权利卫士）与商家巡检工具（Damage iD）都没有；
  2. 对抗立场——垂直工具服务商家，我们只服务用户（"他记他的，你记你的"）；
  3. 产出物是"可出示的凭证 + 申诉材料包"，而非勾选完成度。
- **技术现状**（事实）：单文件 H5/PWA（34KB）零依赖；内容引擎（SCENES/FLOWS 纯 JSON）与渲染层分离——白标换壳零重写；endTs 计时引擎 + 挂起恢复为事件时间轴（V1）预留了技术底座；SW network-first + 自动更新。
- **技术壁垒定性**：工具层无壁垒（确认）；可积累壁垒 = 场景模板库 + 纠纷胜率判例数据 + 台账迁移成本，窗口期 12–18 个月 **[假设]**。
- **路线图**：V1 事件时间轴+服务号触达+云加密备份（付费）；V2 Memo 台账+订阅；V3 小程序+B 端白标。
